# Predicting Perceived Emotion from Movie Clips

Term project. We predict the perceived (intended) emotion of short movie clips (3 s or 10 s) as valence and arousal, using the COGNIMUSE dataset (7 movies, last ~30 min of each, annotated at 25 values per second).

## How to Recreate the Dataset

Due to copyright restrictions on commercial Hollywood films, raw movie video and audio files are excluded from this repository via `.gitignore`. The complete dataset can be reconstructed from scratch using the following steps:

1. **Obtain Annotations & Movies:**
   - Place the COGNIMUSE continuous emotion annotation files (`intended_1_<Movie>.dat`) into `data/annotations/`.
   - Acquire digital copies of the 7 COGNIMUSE films (*A Beautiful Mind*, *Chicago*, *Crash*, *The Departed*, *Finding Nemo*, *Gladiator*, *The Lord of the Rings: Return of the King*) along with English `.srt` subtitles and place them in `data/raw/`.

2. **Pre-trained Model Weights:**
   - The audio encoder (`audeering/wav2vec2-large-robust-12-ft-emotion-msp-dim`) downloads automatically from HuggingFace on first execution.
   - Place `EmotionCLIP-V2.pth` (from `jiangchengchengNLP/EmotionCLIP-V2`) into `pretrained/EmotionCLIP-V2.pth`.

3. **Synchronize & Slice Clips:**
   - Run the automated preprocessing script:
     ```powershell
     python scripts/prep_all_movies.py
     ```
   - This retimes the audio/video to match the 25 fps COGNIMUSE timeline using subtitle alignment, slices 10-second and 3-second clips with 16 kHz mono `.wav` audio and `.mp4` video into `data/clips/`, and calculates ground truth emotion labels.

4. **Extract Embeddings:**
   - Extract the frozen neural representations:
     ```powershell
     python scripts/extract_features.py       # 10s feature representations
     python scripts/extract_features_3s.py    # 3s feature representations
     ```
   - Embeddings are cached in `data/features/<MOVIE>_10s.npz` and `data/features/<MOVIE>_3s.npz`.

## Clip labels

Each clip gets one valence and one arousal value from the continuous annotation, in two ways:
- Average: mean over the clip
- Gaussian: weighted mean, frames near the centre of the clip count more (sigma = 0.2 x clip length)

## Prediction pipeline

The pre-trained audio and video models are kept fixed and used as feature extractors. A small network on top is trained to predict valence and arousal (loss: 1 - CCC).

1. Cut a movie into clips (separate audio and video files + labels). The annotated segment is found automatically by matching the COGNIMUSE subtitles of the segment with the movie's own `.srt`, so you need an English `.srt` that fits your movie file:

   ```
   python scripts/prep_clips.py --movie BeautifulMind --video "data/movies/BMI/A.Beautiful.Mind.2001.1080p.BrRip.x264.YIFY.mp4" --srt "data/movies/BMI/A.Beautiful.Mind.2001.1080p.BrRip.x264.YIFY.srt"
   ```

   It prints how many subtitle lines agree and where the segment is (A Beautiful Mind: 54:52 to 1:27:30). Note: the segment is not always the end of the movie.

2. Extract features for all prepared clips:

   ```
   python scripts/extract_features.py
   ```

3. Train (modality: audio, video or both; label: mean or gauss; `--val_movie` keeps one movie for validation):

   ```
   python scripts/train.py --length 10 --modality both --label gauss --val_movie BMI
   ```

4. Interactive Real-Time Demo:

   ```
   python scripts/demo.py --movie CHI --index 165
   ```
